Bundle trong extension được ưu tiên. Nếu không có, tải từ URL này và cache vào Cache Storage.

Thêm giọng từ HuggingFace (qua server)

Tìm và tải `.vfa`/`.vfts` qua API server; bundle được lưu trong Cache Storage và dùng cho lần đọc local tiếp theo.

Context menu vẫn có các lựa chọn riêng: đọc ẩn, popup, tab.

Mỗi dòng “từ gốc = cách đọc”; lưu trong extension. Giá trị phải là âm tiết tiếng Việt hợp lệ: Z nên viết dét hoặc giét; viết zét sẽ bị fallback thành “a”. Local áp dụng trực tiếp; remote gửi `overrides` nếu server hỗ trợ.
