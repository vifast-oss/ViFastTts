Vì sao ViFastTts

Đủ chuẩn để đọc tiếng Việt.
Đủ nhẹ để chạy mọi nơi.

Không phải model đa ngữ gắn thêm tiếng Việt: frontend được thiết kế cho âm tiết Việt, model non-autoregressive chạy tất định và xuất ONNX để dùng lại trên desktop, mobile, extension hay server.

Chuẩn âm tiết Việt

25 âm đầu · 2 âm đệm · 15 âm chính · 11 âm cuối · 6 thanh → 264 vần. Parser vét cạn 49.104 tổ hợp, 0 lỗi; 39K từ thật parse 6.617/6.633.

Nhỏ và nhanh trên CPU

Acoustic 6,1M + vocoder 13,5M. ONNX FP32, RTF ~0,03 trên VPS CPU; không cần GPU, không cần PyTorch khi dùng ONNX.

Chạy offline

Desktop, extension, Android và iOS đóng gói model + ONNX Runtime. Đọc không cần mạng và không gửi văn bản ra ngoài.

Đọc đúng từ khó

Từ điển hơn 200 mục, quy tắc STEM (hoá học, toán, lý, LaTeX), đánh vần OOV và bảng đọc riêng của bạn. Hỗ trợ cụm/domain như khongdich.com.

Tất định, dễ tích hợp

Cùng một câu cho cùng một kết quả. REST /api/tts, stream NDJSON, CLI server, Python engine và ONNX cho mọi stack.

Một model, mọi nền tảng

Windows, macOS, Linux, Android, iOS Simulator, Chrome/Edge, CLI/server và web tĩnh. Cùng model, cùng cách đọc, cùng bộ test.

Kiến trúc

Văn bản → âm tiết →
mel → WAV 24 kHz.

Mỗi âm tiết thành 7 ID (âm đầu, đệm, chính, cuối, thanh điệu, ranh giới, dấu câu). Model dự đoán mel + thời lượng + F0 trong một lượt, vocoder dựng sóng. Không tự hồi quy, không lấy mẫu ngẫu nhiên.

  • 2.942 test pass / 24 skip; ruff sạch, parser audit 0 lỗi.
  • Holdout: mel L1 4,0 dB · duration MAE 1,37 frame.
  • ONNX opset 18, batch và độ dài động, FP32/FP16/INT8.

API & Python

Gọi model bằng
một request.

Demo VPS đã mở API công khai để thử. Muốn chạy riêng, dùng vifasttts server hoặc quickstart Python — cùng engine ONNX, không cần torch.

  • POST
    /api/tts

    Trả WAV 24 kHz. Nhận text, speed, alpha, dialect, overrides.

  • POST
    /api/tts/stream

    NDJSON: units → audio PCM16 → done; dùng cho phát ngay.

  • GET
    /api/config

    Giới hạn, defaults và capabilities để UI tự cấu hình.

  • GET
    /api/overrides

    Từ điển có sẵn, quy tắc đã duyệt và ví dụ STEM.

  • POST
    /api/feedback

    Góp ý/báo lỗi; nội dung chỉ admin xem.

  • GET
    /healthz

    Trạng thái model, arch, vocab hash, alpha.

Demo công khai: tối đa 3000 ký tự, 6 lượt/phút/IP, không lưu văn bản hay audio. Hợp đồng đầy đủ: docs/API_CONTRACT.md ↗

git clone https://github.com/vifast-oss/ViFastTts.git
cd ViFastTts
./scripts/run_ngochuyen_demo.sh

Windows PowerShell:

powershell -ExecutionPolicy Bypass -File .\scripts\run_ngochuyen_demo.ps1

CLI ONNX (không cần torch)

Cài package và gọi trực tiếp bằng ONNX Runtime + numpy.

cd ViFastTts
pip install -e ".[onnx]"
vifasttts synthesize-onnx \
  --acoustic acoustic.onnx \
  --vocoder vocoder.onnx \
  --text "Xin chào" \
  --output out.wav

Dùng thương mại được không?

Code repo là MIT, nhưng model mẫu và dataset ngochuyen_voice là CC BY-NC 4.0 — chỉ dùng nghiên cứu/phi thương mại. Không dùng để giả giọng, lừa đảo hoặc bán lại khi chưa có quyền riêng.

Cần GPU hay Python không?

Không, với app desktop, extension và mobile: model + ONNX Runtime đã đóng gói. Python chỉ cần khi chạy quickstart/dev hoặc train; ONNX chạy CPU là đủ cho demo và phần lớn nhu cầu.

Vì sao chỉ có một giọng?

Mỗi checkpoint là một người nói, một phương ngữ — không cần speaker_id hay audio mẫu. Muốn giọng khác, train checkpoint mới theo docs/TRAINING_N0.md rồi export ONNX.

macOS Intel có bản không?

Bản phát hành hiện chỉ có arm64 (Apple Silicon). Máy Intel có thể dùng web demo, Python/ONNX hoặc build từ source; xem docs/INSTALL.md.

App có trên App Store / CH Play chưa?

Chưa. Android là APK debug (cài ngoài store); iOS chỉ chạy Simulator, chưa ký Apple Developer. Desktop cũng chưa ký số nên có cảnh báo SmartScreen/Gatekeeper.

Demo có lưu văn bản hay audio không?

Không lưu văn bản hay audio. Server chỉ ghi thống kê ẩn danh (số ký tự, thời lượng, thời gian xử lý, hash visitor), không lưu IP/text; góp ý chỉ admin xem khi đã đặt mật khẩu.

RTF ~0,03 nghĩa là gì?

RTF = thời gian xử lý chia cho thời lượng audio; nhỏ hơn 1 là nhanh hơn thời gian thực. Con số ~0,03 đo trên VPS CPU với ONNX; máy yếu hơn sẽ chậm hơn, máy mạnh hơn có thể nhanh hơn.

Làm sao báo lỗi hoặc góp ý?

Dùng form Góp ý ngay trên trang này. Nếu là lỗi cài đặt, kèm hệ điều hành, file đã tải và thông báo lỗi để dễ tái hiện.
